# Web design

A quiet archival catalog with an olive paper sidebar and compact artwork/text rows. The collection itself is the main visual content; no dashboard hero or fabricated statistics.

Tokens: paper #f7f6f0, ink #26362e, secondary #6d766e, forest #295744, rule #dcdfd5, selected paper #d9e6bb. Avenir Next/system sans handles dense inventory; Iowan Old Style/Palatino gives collection headings an editorial tone. Layout is left aligned: collection rail, searchable rows, optional detail pane. On narrow screens the rail becomes a horizontal selector and details stack below.

Cover art is always adjacent to textual entries; reserved image space avoids layout shifts. Missing covers have a consistent marked placeholder. Tentative identity gets a separate textual status, never an artwork error icon. Navigation and primary actions have visible keyboard focus. No motion is required. Management entrypoints are separate bundles mounted only on permitted listeners.
