# Junk Collector v0.1.0-beta.26

Digital album import review displays a striped file table with separate playback
and sharing controls. Format shortcuts select an alternate encoding while the
import preserves every original. The review can set disc boundaries, reorder
files, and override track numbers before import. An entered track number takes
precedence over the embedded tag. Soundtrack reviews in game collections offer
a switch to an editable music collection.

Signed-in browser pages receive the alternate playback origins they need.
Anonymous responses and static assets omit those origins. The container build
context excludes local configuration and deployment environment backups.

The routine split-host update checker verifies fresh receipt scans on enabled
connections after the Collector restarts.

Upgrade directly from beta.22 or newer using the
[routine beta update procedure](../../deploy/container/beta-update.md). The
catalog and private SQLite schema versions stay at 15 and 23. Keep the paired
recovery point and install the immutable image reference in the published
release record.
