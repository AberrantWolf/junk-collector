# Junk Collector v0.1.0-beta.34

- Digital album review pairs each file with its selected release track and shows
  AcoustID scores or tentative assignments. Reviewers can use a personal
  AcoustID key to contribute fingerprints from confirmed assignments.
- The player puts icon controls beside the scrubber and gives playback format
  its own space on desktop and mobile.
- Library and workspaces retain visible results through background refreshes.
  The sidebar shows the active collection and account display name. Appearance
  can follow the system or use an explicit light or dark theme.
- The Game catalogs help links to the current Redump downloads page.

Upgrade directly from beta.22 or newer using the
[routine beta update procedure](../../deploy/container/beta-update.md).
The catalog and private SQLite schema versions remain 15 and 23.
