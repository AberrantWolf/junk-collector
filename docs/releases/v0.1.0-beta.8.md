# Junk Collector v0.1.0-beta.8

Selecting a MusicBrainz release now supplies track names even when MusicBrainz
has not registered the imported disc’s Disc ID. Single-disc releases require
matching track positions; multi-disc releases require an unambiguous match or
an explicit disc assignment. Manual titles remain authoritative, and a positive
Disc ID match to another disc still conflicts with an assignment.

**Music → Disc details & checks** now offers **Submit Disc ID to MusicBrainz**
for complete recorded CD layouts whose ID is absent from the selected release.
The link carries the recorded TOC and release ID to MusicBrainz, where you sign
in, review the target disc and confirm the edit. No audio is uploaded. Refresh
that release in Metadata after submitting: the button hides when the refreshed
observation lists the ID, including when you retain an older metadata choice.

These are descriptive metadata and contribution features, not catalog/audio
verification. Missing or unsupported TOCs cannot generate a submission link.

## Installation and recovery

Use `ghcr.io/aberrantwolf/junk-collector:v0.1.0-beta.8` or the immutable digest
in this release’s `release-image.json`. This prerelease advances `preview`;
stable `latest` stays unchanged. Update core and media together with retained
configuration, identities, mounts and media sockets. Do not rerun setup.

Retain the previous image and a complete stopped-server recovery point for
archive, private state and configuration/TLS using the
[existing procedure](../../deploy/container/snapshot-recovery.md). There is no
new archive-format conversion in beta.8. Use the matching complete recovery point
and old image if rollback is needed. No Trash Amp installation is included.
