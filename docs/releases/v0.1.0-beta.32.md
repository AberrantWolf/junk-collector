# Junk Collector v0.1.0-beta.32

- **Original** plays the selected file or presents a raw CD track as a seekable
  16-bit WAV with the original PCM samples.
- **High Bandwidth** is the default. It reuses matching FLAC files and converts
  WAV or CD audio to FLAC on demand. MP3 originals play directly.
- **Low Bandwidth** uses Opus at 128 kbps VBR by default. Change the bitrate in
  Playback settings.

New imports prepare FLAC when explicitly requested. The playback API uses a
`mode` query parameter. See [playback settings and API](../configuration.md#live-playback-format).

Upgrade directly from beta.22 or newer using the
[routine beta update procedure](../../deploy/container/beta-update.md).
The catalog and private SQLite schema versions are 15 and 23. Existing
collections, reviewed track choices and prepared audio carry forward.
