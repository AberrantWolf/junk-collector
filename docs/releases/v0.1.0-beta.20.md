# Junk Collector v0.1.0-beta.20

Digital album matching finds promising releases earlier, compares complete track
lists before optional artwork finishes, and bounds searches for alternate editions.
Metadata review offers independent digital-source and artwork choices, clearer
track mapping, and consistent MusicBrainz/AcoustID search panels. Retained results
are labelled as earlier results; only the release actually in use is marked selected.

Background matching recovers brief catalog contention through the server queue,
without turning it into a failed Job that needs manual retry. Progress, cancellation,
ownership and committed publication survive that handoff. Error feedback now keeps
safe failure causes and distinguishes a completed save from a failed refresh.
Unconfirmed or unreadable queue receipts remain visible across app pages.

Raw masters, accepted metadata/artwork sources, manual authority and unknown module
data remain protected. Already failed Jobs are not resubmitted automatically;
after upgrading, explicitly retry matching requests that previously stopped on
catalog contention. Provider refusals are not treated as contention.

This prerelease advances `preview` and leaves stable `latest` unchanged. Stop
writers and retain a matching Fi private-state/NAS archive recovery pair before
updating. Publication and installation use the exact qualified images.

Qualification, publication, Fi installation and the lossless recovery of a
pre-existing cancelled publication are recorded in the [dated operation
record](../validation/container-beta20-publication-2026-11-03.md).
