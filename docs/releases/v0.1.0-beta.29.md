# Junk Collector v0.1.0-beta.29

The Library can read existing albums while music imports publish. Browsing loads
the first page independently of the result count and refreshes visible entries
as analysis settles.

Music imports support ID3-prefixed FLAC, additional APEv2 MP3 layouts, and
32-bit float WAV. An unreadable alternate records a warning while valid
selected tracks continue through analysis. Float WAV originals stay intact and
can use live FLAC or Opus playback, or saved Opus preparation.

Upgrade directly from beta.22 or newer using the
[routine beta update procedure](../../deploy/container/beta-update.md).
The catalog and private SQLite schema versions stay at 15 and 23. Keep the
paired recovery point and install the immutable image reference in the
published release record.
