# Junk Collector v0.1.0-beta.22

- Prepare albums or batches in FLAC or one of three Opus VBR presets. The
  Library updates readiness for the selected preset as source records and Jobs
  change. Music collections can set an Opus default for CD imports or for both
  CD and digital imports, with an override during review.
- Saved import groups show the newest groups first. Select published albums
  within a group to edit title, artist or digital source in bulk. Results are
  reported per album, and digital source edits apply to digital-only albums.
- Sign-in asks for a username by default. Set `multi_user = false` for a
  single-user installation that uses the saved default account and disables
  account creation. Existing accounts and grants are retained.

See [audio preparation](../audio-preparation.md),
[saved import review](../validation/github-imports-2026-11-07.md) and
[account setup](../configuration.md).

This prerelease uses the `preview` channel. Before updating a split Fi/NAS
installation, stop writers and retain a matched private-state and archive
recovery pair. See the [remote archive runbook](../../deploy/container/remote-archive.md).
