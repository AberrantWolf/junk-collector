# Junk Collector v0.1.0-beta.2

**Beta.2 adds game-disc audio, document attachments and backup-age reminders.**
It targets backed-up home-lab use. Storage and interfaces may still change.

## Corrects withdrawn beta.1

The isolated NAS update found an old music-search table that was incorrectly reused.
Beta.2 rebuilds obsolete catalogs and repairs that bad schema stamp.
Archive records and private accounts stay intact. **Use beta.2 for upgrades.**

## What's new

| Feature | What you get |
| --- | --- |
| **Game-disc CD audio** | Prepare and play AUDIO tracks from standard BINARY CUE/BIN game dumps. Search and audio playlists work too. Game identity, artwork and originals stay intact. [Supported formats](../game-disc-audio.md). |
| **PDF and text attachments** | Attach files up to 20 MiB. Preview PDFs in the browser and bounded, escaped UTF-8 text. Documents default to Curators only; sharing enables Viewer access. |
| **Optional backup-age reminders** | See overdue reminders in Server settings and `doctor`. No automatic media backups or cloud uploads. [Enable reminders](../local-alpha-installation.md#optional-backup-age-reminder). |
| **Upload hardening** | Protected routes reject unauthenticated callers before consuming upload bodies. |

Trash Amp's matching game-audio changes are on `codex/game-disc-audio`.
**This release packages Collector only.**

## Before updating

1. Stop the server. Keep its old image digest.
2. Create a complete recovery point: archive, private state and config/TLS.
   Use [Btrfs snapshots](../../deploy/container/snapshot-recovery.md) where eligible,
   or the [full-backup procedure](../../deploy/container/recovery.md).
3. Follow the [update steps](../../deploy/container/README.md#update).
   **Do not rerun fresh setup on an existing installation.**

Private schema stays **21**. The derived catalog rebuilds to **14**.
After new writes, rollback requires the matching old recovery point and image.
An image-only downgrade is not a recovery plan.

## Supported limits

Game audio excludes CHD, proprietary sound files and unsupported raw timelines.
PDF attachments use the browser viewer; no OCR or structural PDF validation is claimed.
Backup reminders report recorded outcomes or explicitly labelled operator dates.

Physical-device and failure coverage remains limited to dated acceptance.
See the [capability checklist](../release-readiness.md) and [roadmap](../remaining-work.md)
for remaining work.
