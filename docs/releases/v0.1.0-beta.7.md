# Junk Collector v0.1.0-beta.7

Automatic album matching now follows the discs actually imported. A normal
2-disc edition takes precedence over an otherwise compatible 3-disc limited
edition; later identified discs can change the automatic preference. Explicit
manual choices remain authoritative. The Metadata workspace refreshes background
changes while preserving unsaved text edits.

- Available, unambiguously assigned discs can play even when a provider release
  lists additional media. Missing media stays visible in album coverage.
- Matches differing only by Collector’s internal version appear as one choice.
  Periodic maintenance consolidates existing choices without deleting immutable
  sources; new provider responses avoid generating version-only duplicates.
- Security/dependency maintenance updates TLS/QUIC, Tokio, ZIP, shared XML and
  CHD dependencies, bounds XML event processing, replaces the unmaintained PEM
  parser, and updates Utoipa 6 to remove the unmaintained paste dependency.

Edition preference remains descriptive: shared disc layouts do not establish an
exact pressing or catalog/audio verification. Unknown/unprocessed discs remain
inconclusive. Cleanup waits for active workflows and retains manual authority.

## Installation and recovery

Use `ghcr.io/aberrantwolf/junk-collector:v0.1.0-beta.7` or the immutable digest
in this release’s `release-image.json`. This prerelease advances `preview`, with
stable `latest` unchanged. Update core and the separate media service together;
preserve existing configuration, identities, mounts and media socket volumes.
Do not rerun setup.

Before updating, retain the previous image and take a complete stopped-server
recovery point for archive, private state and configuration/TLS using the
[existing procedure](../../deploy/container/snapshot-recovery.md). This release
does not convert original media, but new metadata revisions use resolution policy
4. An older server cannot interpret those revisions: rollback requires restoring
the complete pre-update recovery point together with its matching old image,
rather than changing only the image. No Trash Amp installation is included.
