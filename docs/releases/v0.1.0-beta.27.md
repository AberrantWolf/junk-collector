# Junk Collector v0.1.0-beta.27

Automatic track numbering in Music imports counts only the files selected for
album playback. The count starts at one on each disc of each album, including
when several albums are imported together. Manual track numbers and embedded
track tags still take precedence. The fallback also applies to existing
analyzed albums.

Upgrade directly from beta.22 or newer using the
[routine beta update procedure](../../deploy/container/beta-update.md).
The catalog and private SQLite schema versions stay at 15 and 23. Keep the
paired recovery point and install the immutable image reference in the
published release record.
