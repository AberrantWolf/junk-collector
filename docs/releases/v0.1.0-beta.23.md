# Junk Collector v0.1.0-beta.23

- Start a Library audio preparation batch immediately from the current album
  selection. Album planning runs in the background, with progress, per-album
  results and cancellation in Activity. Cancelled album work settles before
  Retry becomes available.
- Find selectable Proton Bridge mail folders during setup or while editing
  a saved mail connection. Add folders from the picker or enter their exact
  names. Saving preserves the paused or enabled state and existing scan
  positions.

See [audio preparation](../audio-preparation.md) and
[mail setup and folder editing](../email-purchases.md).

This prerelease uses the `preview` channel. Before updating a split-host
installation, stop writers and retain a matched private-state and archive
recovery pair. See the [remote archive runbook](../../deploy/container/remote-archive.md).
