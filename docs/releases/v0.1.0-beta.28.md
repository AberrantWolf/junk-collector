# Junk Collector v0.1.0-beta.28

The Music import review can move sibling audio folders as blocks. Manual track
numbers reserve their positions across a disc, and automatic numbers fill the
open positions. Import uses the reviewed order on affected discs even when
embedded track numbers differ. A saved review retains folder and track order.

Upgrade directly from beta.22 or newer using the
[routine beta update procedure](../../deploy/container/beta-update.md).
The catalog and private SQLite schema versions stay at 15 and 23. Keep the
paired recovery point and install the immutable image reference in the
published release record.
