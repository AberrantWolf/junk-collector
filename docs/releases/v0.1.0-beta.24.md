# Junk Collector v0.1.0-beta.24

- Choose saved audio, FLAC or custom-bitrate Opus in the web player or Account settings.
  The normal authenticated connection can convert supported CD and digital sources live.
- Purchase inbox recognizes Amazon Japan order, shipment and delivery notices with
  order-card item titles and order references. Rescanning can fill missing fields on
  unaccepted suggestions.
- The browser test runner reports active work, bounds fixture teardown and finishes
  independent journeys after a failure.
- The documentation index and accepted architecture decisions separate current
  contracts from historical validation and open work.

Direct upgrade support starts with beta.22. Preserve a consistent archive and private
state recovery point before updating. Live conversion requires FFmpeg, which is
included in the Collector container. Separate media connections serve saved audio.
