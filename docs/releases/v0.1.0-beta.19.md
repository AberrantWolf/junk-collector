# v0.1.0-beta.19

Metadata opens with compact cached rows, loads more entries incrementally and
fetches album detail on demand. Open reviews check a small revision header before
reloading. Artwork remains beside rows, with current access and language checks.

Digital album identification calculates tracks concurrently using the configured
processing budget. AcoustID lookups begin as fingerprints finish, and independent
provider services can overlap. Fresh calculations validate each selected original
once and decode at most the first two minutes. Valid fingerprints and fresh
provider responses are reused; Refresh lookups explicitly requests new recognition
responses without recalculating unchanged audio. Progress shows completed
fingerprints/lookups and release comparison; usable candidates appear before
optional covers finish. Broader release searching remains an explicit action.

Queueing another album preserves earlier requests. Navigation no longer owns the
admission request; unconfirmed requests stay visible with recovery controls.
Work and cancellation survive restart, and Activity groups internal steps under
the album. These are identity suggestions, not catalog verification. Manual
metadata/artwork authority and exact original files remain protected.

This beta also includes complete declared RIFF/WAVE audio with uninterpreted
trailing bytes: usable declared audio is accepted, the suffix warning remains
visible, and the exact original is preserved. Truncated or internally malformed
WAV data still fails closed. Existing failed Jobs are not retried automatically.

The upgrade adds rebuildable caches/indexes and private workflow checkpoints; it
does not compact originals, unknown module records or accepted evidence. Stop
writers and retain matching Fi private-state/NAS archive recovery points before
updating. Install the qualified release image. This prerelease advances `preview`
and leaves stable `latest` unchanged.

See [qualification and limits](../validation/metadata-performance-2026-11-02.md)
and [WAV acceptance](../validation/wav-trailing-bytes-2026-11-02.md).
