# Junk Collector v0.1.0-beta.33

Published imports now release their private staging files after the archive
masters are committed and confirmed present. The server retries interrupted
cleanup and uses the archived bytes for published upload replays. Unfinished
imports retain their staging for recovery. The configured inbox keeps its
separate, explicit source cleanup.

The change applies to existing published staging as well. Read-only recovery
snapshots can continue to hold staging bytes until those snapshots are retired.

Upgrade directly from beta.22 or newer using the
[routine beta update procedure](../../deploy/container/beta-update.md).
The catalog and private SQLite schema versions remain 15 and 23.
